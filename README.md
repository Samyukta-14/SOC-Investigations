# SOC-Investigations
A collection of SOC investigation write-ups from an enterprise-grade cyber range environment. Each case documents a full investigation from initial alert through to detection rules, mitigation, and lessons learned. They are written from the perspective of a SOC analyst working the incident.

## Cases
1. Windows Mass Defacement
2. Phishing Attack
3. Ransomware
4. Data Breach
5. Bitcoin Mining

## Structure
 
Each case follows the same format:
 
- Scenario
- Investigation approach with MITRE ATT&CK mapping and screenshots
- Detection rules
- Mitigation and remediation
- Lessons learned
